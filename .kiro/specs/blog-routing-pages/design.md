# 設計書

## 概要

シンプルなクライアントサイドルーティングを使用して、ランディングページと10個のブログ記事ページを持つウェブサイトを実装します。JavaScriptを使用してSPA（Single Page Application）のような動作を実現し、ページ遷移時にサーバーへのリクエストなしでコンテンツを切り替えます。

## アーキテクチャ

### 技術スタック

- HTML5
- CSS3（既存のスタイルを拡張）
- Vanilla JavaScript（フレームワークなし）

### ファイル構造

```
/
├── index.html              # メインHTMLファイル（ルーター含む）
├── js/
│   ├── router.js          # ルーティングロジック
│   ├── pages.js           # ページコンテンツ定義
│   └── app.js             # アプリケーション初期化
└── README.md
```

## コンポーネントとインターフェース

### 1. Router モジュール

**責務**: URLパスに基づいてページコンテンツを切り替える

**主要メソッド**:

- `init()`: ルーターを初期化し、イベントリスナーを設定
- `navigate(path)`: 指定されたパスに遷移
- `handleRoute()`: 現在のURLパスに基づいてページをレンダリング
- `render(pageContent)`: ページコンテンツをDOMに挿入

**イベント処理**:

- `popstate`: ブラウザの戻る/進むボタンに対応
- `click`: リンククリックをインターセプトしてSPA遷移を実現

### 2. Pages モジュール

**責務**: 各ページのコンテンツとメタデータを管理

**データ構造**:

```javascript
{
  id: string,           // 記事ID
  title: string,        // 記事タイトル
  icon: string,         // 絵文字アイコン
  summary: string,      // 要約
  date: string,         // 公開日
  category: string,     // カテゴリー
  content: string       // 本文HTML
}
```

**提供する記事**:

1. 朝の習慣で人生が変わる（自己啓発）
2. 簡単で美味しい時短レシピ（料理）
3. ストレス解消法10選（健康）
4. 在宅ワークの生産性向上術（仕事）
5. 週末に行ける国内旅行スポット（旅行）
6. 初心者向けヨガガイド（健康）
7. 読書習慣を身につける方法（趣味）
8. 節約しながら楽しむライフスタイル（お金）
9. デジタルデトックスのすすめ（健康）
10. 趣味を見つける10のヒント（趣味）

### 3. App モジュール

**責務**: アプリケーション全体の初期化と調整

**主要メソッド**:

- `init()`: ルーターとイベントリスナーを初期化

## 正確性プロパティ

正確性プロパティとは、システムが満たすべき普遍的な特性や動作のことです。これらは、すべての有効な実行において真であるべき形式的な記述です。

### プロパティ1: ナビゲーションの一貫性

*すべての*有効なブログ記事IDに対して、そのIDへのナビゲーションは対応するブログページを表示し、URLは `/blog/{id}` の形式になるべきである

**検証: 要件 1.1, 1.4**

### プロパティ2: 履歴の整合性

*すべての*ページ遷移に対して、ブラウザの戻るボタンを押した後に進むボタンを押すと、元のページに戻るべきである

**検証: 要件 1.2, 1.3**

### プロパティ3: コンテンツの完全性

*すべての*ブログページに対して、タイトル、本文、公開日、ホームへのリンクが含まれているべきである

**検証: 要件 2.2, 2.3**

### プロパティ4: ランディングページのリンク完全性

*すべての*ブログ記事に対して、ランディングページにその記事へのリンクが存在するべきである

**検証: 要件 3.1, 3.2**

## エラーハンドリング

### 存在しないパスへのアクセス

- 未定義のパスにアクセスした場合、ランディングページ（`/`）にリダイレクト
- コンソールに警告メッセージを出力

### JavaScriptが無効な場合

- 基本的なHTMLコンテンツは表示される
- ルーティング機能は動作しないが、ページは閲覧可能
