# 実装計画: ブログルーティングとページ

## 概要

クライアントサイドルーティングを実装し、10個のブログ記事ページを作成します。既存のランディングページを更新して、各記事へのリンクを追加します。

## タスク

- [x] 1. JavaScriptファイルの構造を作成
  - jsディレクトリを作成
  - router.js、pages.js、app.jsファイルを作成
  - _要件: 5.1, 5.2_

- [x] 2. ブログ記事データを定義
  - [x] 2.1 pages.jsに10個のブログ記事オブジェクトを作成
    - 各記事にid、title、icon、summary、date、category、contentを含める
    - 健康、料理、旅行、趣味、仕事、自己啓発などの多様なカテゴリーをカバー
    - 各記事の本文は最低300文字以上
    - _要件: 2.1, 2.2, 4.1, 4.3_

- [x] 3. ルーティング機能を実装
  - [x] 3.1 router.jsにルーター初期化関数を実装
    - URLパスを解析する関数
    - ページをレンダリングする関数
    - ナビゲーション関数（履歴API使用）
    - _要件: 1.1, 1.4, 5.1, 5.3_
  - [x] 3.2 ブラウザ履歴対応を実装
    - popstateイベントリスナーを追加
    - 戻る/進むボタンでページ遷移を処理
    - _要件: 1.2, 1.3_
  - [x] 3.3 リンククリックのインターセプト機能を実装
    - すべての内部リンクをSPA遷移に変換
    - 外部リンクは通常の動作を維持
    - _要件: 1.1, 3.2_

- [x] 4. ブログページテンプレートを作成
  - [x] 4.1 ブログ記事表示用のHTML生成関数を実装
    - タイトル、公開日、カテゴリー、本文を表示
    - ホームへ戻るリンクを含める
    - 既存のCSSスタイルと一貫性を保つ
    - _要件: 2.2, 2.3, 2.4_

- [x] 5. ランディングページを更新
  - [x] 5.1 index.htmlのブログカードセクションを動的に生成
    - 10個の記事へのリンクを表示
    - 各カードにタイトル、要約、アイコンを表示
    - _要件: 3.1, 3.3_
  - [x] 5.2 index.htmlにJavaScriptファイルを読み込む
    - script タグを追加（app.js、router.js、pages.js）
    - _要件: 1.1_

- [x] 6. エラーハンドリングを実装
  - [x] 6.1 存在しないパスへのアクセス処理
    - 未定義のパスはランディングページにリダイレクト
    - コンソールに警告を出力
    - _要件: 1.5_

- [x] 7. アプリケーション初期化
  - [x] 7.1 app.jsにアプリケーション初期化コードを実装
    - DOMContentLoadedイベントでルーターを初期化
    - 初期ページをレンダリング
    - _要件: 1.1, 1.4_

- [ ] 8. チェックポイント - すべての機能が動作することを確認
  - すべてのページ遷移が正しく動作するか確認
  - ブラウザの戻る/進むボタンが機能するか確認
  - レスポンシブデザインが維持されているか確認
  - ユーザーに質問があれば確認

## 注意事項

- 既存のindex.htmlのデザインとスタイルを維持
- JavaScriptはVanilla JSを使用（フレームワーク不要）
- すべてのページでレスポンシブデザインを確保
- ブラウザ互換性を考慮（モダンブラウザ対応）
